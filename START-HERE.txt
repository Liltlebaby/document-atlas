Document Atlas Web สำหรับ Windows Server x64
ชุดติดตั้งครบระบบ วันที่ 9 พฤศจิกายน 2026

1. แตก DocumentAtlas-Web-Windows-x64-2026-11-09-Full.zip แล้วเปิด README-IT.md
2. ใช้ ZIP นี้ไฟล์เดียว มีอัปเดตหน้ามือถือและสคริปต์เริ่มระบบล่าสุดรวมมาแล้ว
   ในคู่มือ Word ให้ใช้ชื่อ ZIP นี้แทนชุด LAN และข้ามขั้นตอนลง ZIP อัปเดตมือถือ
3. สร้างบัญชีด้วย New-AtlasAccount.ps1 และเริ่มเว็บด้วย Start-Atlas.ps1
4. ให้ IT ตั้ง URL HTTPS บริษัทสำหรับคอมพิวเตอร์และมือถือ ทำตามหัวข้อ 2 ใน README-IT.md
5. ให้ IT ลงชื่อเข้าใช้ Codex ที่ได้รับอนุญาตและเปิดถามตอบตามหัวข้อ 3 ใน README-IT.md

public          หน้าเว็บที่สร้างเสร็จแล้ว รองรับคอมพิวเตอร์และมือถือ
source          ซอร์สเว็บ React และเซิร์ฟเวอร์ Rust พร้อมไฟล์ล็อกเวอร์ชัน

data            ดัชนี RAG โมเดล BGE-M3 ไฟล์ PDF และผลคัดแยก ISO
desktop         ตัวติดตั้งและซอร์ส Desktop สำหรับดูแลดัชนี
docs            MEMO และคู่มือ Word
